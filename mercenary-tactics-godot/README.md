# 흐린 달의 용병단 — Godot Tactical Prototype

Godot 4.3+용 PC 프로토타입입니다. 기존 웹 프로토타입과 별도 프로젝트입니다.

## 실행
1. Godot 4.3 이상 설치
2. Godot Project Manager에서 `project.godot` 선택
3. 프로젝트 열기
4. `F6` 또는 `F5` 실행

## 현재 구현
- 8×8 논리 전투판
- 사다리꼴 2.5D 화면 투영
- 앞/뒤 2줄 배치존 시각 구분
- 좌우로 반드시 이어지는 랜덤 강
- 강 위 랜덤 다리 2곳
- 랜덤 숲 / 바위
- 강/바위 이동 불가
- 숲 이동 비용 2
- 다리 통행 가능
- 세라 SD 투명 PNG
- 이동력 3 범위 하이라이트
- 타일 클릭 이동
- 경로를 한 칸씩 자연스럽게 이동
- 이동 중 살짝 들리는 hop
- 그림자 축소/복원
- 착지 squash
- 직접 생성한 짧은 달그락 WAV 사운드
- R키 또는 버튼으로 전장 재생성
